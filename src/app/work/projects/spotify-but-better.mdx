## Overview

**Sonder** is a fast, distraction-free, open-source desktop music player built with **Tauri** and **Rust**. Created as a lightweight native alternative to bloated streaming clients, Sonder organizes music directly from local filesystem directories into clean playlists with zero ads and minimal RAM usage.

## Architecture & Features

- **Native Tauri + Rust Footprint**: Uses a fraction of the memory consumed by Electron-based music players while delivering native OS window integration.
- **Filesystem-First Playlists**: Automatically indexes local audio folders into playlists without requiring proprietary database lock-in.
- **Seamless Companion to Spotify Song Scraper**: Pairs with local audio libraries and metadata scrapers for offline-first listening.
