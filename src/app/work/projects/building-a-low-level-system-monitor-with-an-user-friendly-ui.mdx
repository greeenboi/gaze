## Overview

A low-level system monitor with a real-time web interface built in **Rust**. It collects CPU, memory, disk, and process telemetry across multi-threaded worker pools—interfacing with native OS performance counters on Windows (PowerShell Counter cmdlets) and macOS—and streams live metrics to a clean browser dashboard.

## Key Features

- **Multi-Threaded Telemetry Engine**: Asynchronous Rust worker threads sample system counters with minimal CPU and memory overhead.
- **Remote Server Tunneling**: Designed to run headless on a server or workstation and expose a lightweight web interface over a secure tunnel.
- **Real-Time Utilization Charts**: Live visualization of per-core CPU load, memory pressure, network throughput, and active processes.
