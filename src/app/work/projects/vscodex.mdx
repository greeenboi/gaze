## Overview

**VSCodex** is a lightweight desktop code editor engineered with **Tauri**, **Vite**, and **CodeMirror**. It provides instant startup times and a minimal memory footprint while supporting syntax highlighting across multiple programming languages, customizable editor themes, and fast local file editing.

## Key Capabilities

- **Sub-Second Startup**: Powered by Tauri's native webview and Rust backend instead of bundling a full Chromium runtime.
- **Multi-Language CodeMirror Engine**: Rich syntax highlighting, bracket matching, and keybindings for modern web and systems languages.
- **Custom Theming**: Clean, distraction-free interface with switchable editor color schemes.
